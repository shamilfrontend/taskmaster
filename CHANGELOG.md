# Changelog

Все заметные изменения Taskmaster фиксируются в этом файле.

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии: [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added

- Роли на проекте: состав назначается из команды, роль независима от командной. Owner команды видит все проекты и управляет составом.
- Редактирование своих комментариев с меткой «изменён».
- Unit-тесты клиента на Vitest (`jsdom`, `@vue/test-utils`): снепшот `App.vue`, скрипты `npm test` / `npm run test:watch`.
- Переименование проекта из меню действий в списке команды и из вкладки «Настройки».
- Ответы на комментарии карточки: один уровень вложенности, кнопка «Ответить», удаление корня снимает ответы.

### Changed

- Экраны проекта открываются по вложенным URL: доска `/projects/:id`, релизы `/projects/:id/releases`, релиз `/projects/:id/releases/:releaseId`, аналитика `/projects/:id/analytics`, настройки `/projects/:id/settings`. Старые адреса (`?tab=`, `/releases/:id`) редиректятся.
- CI: после линта запускаются unit-тесты клиента; деплой на `main` зависит от успешного `test`.
- Лендинг адаптирован под телефоны и планшеты: сетка карточек 3/2/1, hero-скриншот во всю ширину экрана, кнопки CTA в столбик.
- В шапке лендинга осталась одна кнопка «Войти через Яндекс ID»; демо-доступ доступен из hero и блока CTA.

## [0.2.2] — 2026-08-17

### Changed

- CI и деплой в одном workflow: сначала линт, затем деплой на `main`.

## [0.2.1] — 2026-08-17

### Fixed

- На лендинге больше не показывается баннер «Нужна авторизация» для гостей.

## [0.2.0] — 2026-08-17

Проект открывается как одна канбан-доска со вкладками. Доска больше не отдельная сущность в UI.

### Added

- Вкладки проекта: Доска / Релизы / Аналитика / Настройки (релизы и настройки — по флагу и роли).
- Опциональные релизы и бюджет на проекте (`releasesEnabled`, `budgetEnabled`).
- Фон канбана: набор фонов, сохраняется в проекте.
- Описание карточки и чеклисты.
- Лента активности: создание карточки, перемещение, комментарий.
- Переключатель продуктов в шапке и хлебные крошки по текущему контексту.
- Колонка «На проверке» в доске по умолчанию.
- Стили на SCSS вместо CSS.
- Dashboard аналитики: кольцо статусов, тренд списаний и загрузка участников.
- Прогресс план/факт и бюджета, клик по риску открывает карточку.
- Часы в недельной разбивке аналитики (график работает и без бюджета).
- Клик по KPI и статусу в аналитике открывает доску с фильтром.
- Лендинг для гостей: возможности продукта и вход через Яндекс ID.
- Создание проекта из JSON-экспорта доски Trello.
- Демо-доступ с лендинга: вход без Яндекса и команда «Наша команда» с данными.
- Демо: проект «CRM-система» с релизами, карточками и списаниями за ~2 года.
- В демо-доступе записи блокируются, показывается тост.
- ESLint для client и server, Husky pre-commit и GitHub Actions CI.

### Changed

- Маршрут проекта — канбан; релизы и настройки — вкладки той же страницы.
- Карточка открывается модалкой поверх доски с полным редактированием.
- Упрощено владение командой: роль Owner только у создателя, через инвайт и смену роли не выдаётся.
- Обновлены экраны команд, приглашений, входа и аналитики под новый UI.
- Экран аналитики: KPI без исполнителя и оценки, состояния загрузки и пустых панелей.
- Доска: фильтры исполнителя, меток и релиза пишутся в URL.
- Вкладки команды: вместо Обзора — Действия с подгрузкой активности.
- Фильтры аналитики: периоды Сегодня, 3 года и 5 лет.
- Фоны доски отдаются локально, без Unsplash.
- README: чеклист v1 и описание деплоя.

### Removed

- Отдельный экран доски как самостоятельной сущности.
- Набор логотипов в корне (`logo/`), кроме публичного `kanban.svg`.

## [0.1.1] — 2026-08-14

### Added

- Хлебные крошки по команде, проекту и доске.

### Changed

- Канбан: удобнее колонки, карточки и действия на доске.
- CI/CD: правки GitHub Actions и Docker Compose для деплоя на VPS.

## [0.1.0] — 2026-08-14

Первый MVP.

### Added

- Вход через Яндекс ID (OAuth), JWT в httpOnly cookie.
- Команды, роли Owner / Admin / Member / Viewer.
- Одноразовые приглашения со ссылкой и ролью.
- Проекты с канбан-доской: колонки, карточки, метки, комментарии.
- Релизы проекта: planned / released, привязка карточки к релизу.
- Списания часов, ставки (роль / персональная), бюджет проекта в RUB.
- Аналитика проекта: сводка, статусы, план/факт, загрузка, риски.
- Деплой: Docker Compose, Caddy (HTTPS), GitHub Actions → VPS.
