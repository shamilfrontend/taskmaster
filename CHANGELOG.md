## [Unreleased]

## [0.2.0] — 2026-08-15

Проект открывается как одна канбан-доска со вкладками. Доска больше не отдельная сущность в UI.

### Added

- Вкладки проекта: Доска / Релизы / Аналитика / Настройки (релизы и настройки — по флагу и роли).
- Опциональные релизы и бюджет на проекте (`releasesEnabled`, `budgetEnabled`).
- Фон канбана: набор фонов, сохраняется в проекте.
- Описание карточки и чеклисты.
- Лента активности: создание карточки, перемещение, комментарий.
- Переключатель продуктов в шапке и хлебные крошки по текущему контексту.
- Колонка «На проверке» в доске по умолчанию.
- Стили на SCSS вместо CSS.

### Changed

- Маршрут проекта — канбан; релизы и настройки — вкладки той же страницы.
- Карточка открывается модалкой поверх доски с полным редактированием.
- Упрощено владение командой: роль Owner только у создателя, через инвайт и смену роли не выдаётся.
- Обновлены экраны команд, приглашений, входа и аналитики под новый UI.

### Removed

- Отдельный экран доски как самостоятельной сущности.
- Набор логотипов в корне (`logo/`), кроме публичного `kanban.svg`.

## [0.1.1] — 2026-08-14

### Added

- Хлебные крошки по команде, проекту и доске.

### Changed

- Канбан: удобнее колонки, карточки и действия на доске.
- CI/CD: правки GitHub Actions и Docker Compose для деплоя на VPS.

## [0.1.0] — 2026-08-14

Первый MVP.

### Added

- Вход через Яндекс ID (OAuth), JWT в httpOnly cookie.
- Команды, роли Owner / Admin / Member / Viewer.
- Одноразовые приглашения со ссылкой и ролью.
- Проекты с канбан-доской: колонки, карточки, метки, комментарии.
- Релизы проекта: planned / released, привязка карточки к релизу.
- Списания часов, ставки (роль / персональная), бюджет проекта в RUB.
- Аналитика проекта: сводка, статусы, план/факт, загрузка, риски.
- Деплой: Docker Compose, Caddy (HTTPS), GitHub Actions → VPS.
