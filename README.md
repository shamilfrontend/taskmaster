# Taskmaster

Трекер задач в стиле Trello: проект — канбан-доска с колонками, карточками и релизами внутри команд. Ролевая модель, списание часов и аналитика.

**Статус:** v1 готов, дальше — пункты «Вне v1».

- `[x]` — сделано
- `[ ]` — не сделано

**Стек:** Vue 3 + TypeScript, Pinia, axios / Express + Mongoose / MongoDB.

Техническая карта: [docs/](docs/README.md) — архитектура, поля моделей, маршруты SPA и REST API.

## Авторизация

- [x] Вход через **Яндекс ID** (OAuth). Локальный логин/пароль не используется: аккаунт создаётся или подключается при первом входе через Яндекс
- [x] После OAuth выдаётся JWT в **httpOnly cookie**, TTL 7 дней, без refresh в v1. Logout очищает cookie
- [x] Храним у пользователя: `yandexId`, `displayName`, `email`, `avatarUrl`
- [x] Демо-вход с лендинга: команда «Наша команда» с данными, записи блокируются (тост)

## Роли

Есть два слоя: **команда** и **проект**. Командная роль не копируется на проект автоматически.

### Команда

Роль задаётся на команду: инвайты, состав команды, создание проекта, удаление команды.

| Действие | Owner | Admin | Member | Viewer |
| --- | --- | --- | --- | --- |
| Просмотр команды | да | да | да | да |
| Участники и инвайты | да | да | нет | нет |
| Создание проекта | да | да | нет | нет |
| Удаление команды | да | нет | нет | нет |

Owner команды видит все проекты и может управлять их составом, даже если его не добавили в проект.

### Проект

Доступ только у участников проекта (и у Owner команды). Роль на проекте независима от командной. При создании в составе только создатель — Owner проекта.

| Действие | Owner | Admin | Member | Viewer |
| --- | --- | --- | --- | --- |
| Просмотр проекта, доски, релизов, аналитики | да | да | да | да |
| Карточки (создание, правки, перемещение, релиз) | да | да | да | нет |
| Комментарии | да | да | да | нет |
| Списание часов | любые | любые | свои карточки | нет |
| Состав проекта | да | да (не Owner и не другого Admin) | нет | нет |
| Настройки, колонки, метки, релизы | да | да | нет | нет |
| Удаление проекта | да | да | нет | нет |

- [x] Матрица ролей команды
- [x] Матрица ролей проекта
- [x] Создатель команды становится Owner
- [x] Создатель проекта становится Owner проекта

## Правила

### Инвайт

- [x] Ссылка одноразовая: после принятия токен недействителен
- [x] Роль в инвайте: Admin / Member / Viewer. Owner через инвайт не выдаётся
- [x] Без привязки к email: кто первый вошёл через Яндекс и открыл ссылку — тот вступает
- [x] Уже в команде — повторно не вступает, ссылка сгорает
- [x] Неиспользованный инвайт можно отозвать (Owner/Admin). Срок: 7 дней

### Доступ

Проект видят только его участники. Owner команды видит все проекты команды.

- [x] **Owner / Admin проекта** — настройки, колонки, метки, релизы, любые списания
- [x] **Member проекта** — карточки и списание часов на своих карточках
- [x] **Viewer проекта** — проект (канбан), карточки и релизы без правок

### Участники команды

- [x] Смена роли и исключение: Owner — любого; Admin — только Member/Viewer (не Owner и не другого Admin)
- [x] Роль Owner через смену роли не назначается. Команда без Owner невозможна
- [x] Выход из команды: Member/Viewer/Admin сами; Owner выйти не может
- [x] Исключённый: снимается с проектов команды, `assigneeId` на его карточках → `null`; списания остаются

### Участники проекта

- [x] Добавить можно только участника этой команды, роли Admin / Member / Viewer
- [x] Смена роли и исключение: Owner проекта и Owner команды — любого кроме Owner проекта; Admin проекта — только Member/Viewer
- [x] Owner проекта нельзя исключить и нельзя выйти. Owner через смену роли не назначается
- [x] Исполнитель карточки выбирается из участников проекта

### Карточка и списания

- [x] Открывается модалкой/drawer поверх доски
- [x] Описание и чеклисты
- [x] Списывает всегда текущий пользователь; в загрузке часы идут на него
- [x] Member создаёт, правит и удаляет только свои записи и только если он текущий исполнитель карточки
- [x] Owner/Admin — любые записи на любых карточках (в том числе «за себя» на чужой)
- [x] Перемещение — только между колонками этой доски; порядок в колонке — поле `position`
- [x] Часы списания: `0.5 … 24`, шаг 0.5. Оценка: `0 … 1000`, шаг 0.5
- [x] Колонки по умолчанию: «К выполнению», «В работе», «На проверке», «Готово» (`isDone` только у «Готово»)
- [x] Owner/Admin: переименовать, порядок, добавить, удалить колонку. Удаление запрещено, если в колонке есть карточки
- [x] Просрочка: `dueDate < сегодня` и карточка не в колонке с `isDone`
- [x] Метки принадлежат доске. Создать и удалить — Owner/Admin; назначить на карточку — Member+
- [x] Переименовать метку
- [x] Комментарии: все кроме Viewer; автор может править свой (метка «изменён», без истории). Удаляет автор либо Owner/Admin. Можно ответить (один уровень: ответы висят на корневом комментарии; удаление корня удаляет ответы)
- [x] Релиз на карточке опционален: одна карточка — один релиз или без релиза

### Релиз

- [x] Принадлежит проекту. Название уникально в рамках проекта (trim, без учёта регистра)
- [x] Поля: название, дата (можно пустую), статус `planned` | `released`
- [x] При создании статус всегда `planned`; поле статуса в форме create игнорируется. Смена статуса — отдельное действие Owner/Admin
- [x] Карточка ссылается через `releaseId`. Без релиза допустимо
- [x] Статус информационный: к `released` можно прикреплять карточки (хотфиксы). Смена статуса не двигает карточки по колонкам
- [x] Создать, править, сменить статус, удалить — Owner/Admin
- [x] Прикрепить и открепить карточку — кто может править карточки (Member+)
- [x] Viewer только смотрит

### Удаление

- [x] Команда — только Owner (каскадом проекты, карточки, релизы)
- [x] Проект — Owner/Admin, каскадом колонки, карточки, релизы
- [x] Релиз — Owner/Admin; карточки остаются, `releaseId` сбрасывается
- [x] Карточка без списаний — Member/Admin/Owner; со списаниями — только Owner/Admin

## Аналитика

Скоуп: один проект и период. Вкладка и API доступны только если на проекте включён `analyticsEnabled` (по умолчанию выключен).

- [x] Пресеты: сегодня / 7 дней / 30 дней / квартал / год / 3 года / 5 лет (от сегодня)
- [x] Произвольный date range
- [x] Сводка, статусы колонок, риски, релизы «готово / всего» — **снимок сейчас**, не фильтр по дате
- [x] «Готово» = колонка с `isDone`, не сравнение по имени
- [x] Статусы — по колонкам единственной доски проекта; «без релиза» — отдельная строка
- [x] План vs факт (часы), загрузка, списания по неделям — списания с `workedAt` в периоде; план — текущие оценки
- [x] Риски: просрочено, срок на этой неделе, дыры (нет исполнителя / оценки / релиза)
- [x] Сводка: число карточек, просроченные, без исполнителя, без оценки, без релиза

## Деплой

| Параметр | Значение |
| --- | --- |
| **Хостинг** | VPS Beget, Ubuntu 26.04 |
| **Домен** | [taskmaster.shamilfrontend.ru](https://taskmaster.shamilfrontend.ru) |
| **Контейнеры** | Docker: frontend, backend, MongoDB |
| **Прокси / HTTPS** | Caddy (TLS и reverse proxy к frontend/backend) |
| **CI/CD** | GitHub Actions → SSH на VPS |

### Docker

- `frontend` — SPA (Vue 3)
- `backend` — API (Express)
- `mongodb` — БД (только внутри Compose, наружу не открывать)

Сборка и запуск через Docker Compose на VPS. Caddy терминирует HTTPS и проксирует на контейнеры.

`YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `JWT_SECRET` и `YANDEX_REDIRECT_URI` — GitHub Secrets; CI пишет их в `/opt/taskmaster/.env` на VPS.

### Первый деплой

1. DNS: A-запись `taskmaster` → IPv4 VPS. Проверка: `dig +short taskmaster.shamilfrontend.ru`
2. На VPS один раз (под `DEPLOY_USER`):

```bash
sudo apt-get update
sudo apt-get install -y git ca-certificates curl
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker "$USER"
sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw --force enable
sudo systemctl disable --now nginx apache2 2>/dev/null || true
```

Перелогинься, проверь `docker compose version`. Публичный ключ от `DEPLOY_SSH_KEY` — в `~/.ssh/authorized_keys`.

3. GitHub Secrets:

| Secret | Назначение |
| --- | --- |
| `DEPLOY_HOST` | Хост VPS |
| `DEPLOY_PORT` | SSH-порт |
| `DEPLOY_USER` | Пользователь SSH |
| `DEPLOY_SSH_KEY` | Приватный ключ для деплоя |
| `YANDEX_CLIENT_ID` | OAuth-приложение Яндекс ID |
| `YANDEX_CLIENT_SECRET` | Секрет OAuth-приложения |
| `JWT_SECRET` | `openssl rand -hex 32` |
| `MONGO_INITDB_ROOT_PASSWORD` | `openssl rand -hex 24` |
| `YANDEX_REDIRECT_URI` | `https://taskmaster.shamilfrontend.ru/api/auth/yandex/callback` |

4. oauth.yandex.ru: добавь тот же Callback URI. Локальный `http://localhost:3000/api/auth/yandex/callback` не удаляй.
5. Push в `main` → Actions → SSH → `git clone`/`pull` в `/opt/taskmaster` → `.env` → `docker compose up -d --build`
6. Проверка: `https://taskmaster.shamilfrontend.ru/api/health` → `{"ok":true}`

Если TLS не выдался — DNS ещё не дошёл или 80/443 закрыты.
